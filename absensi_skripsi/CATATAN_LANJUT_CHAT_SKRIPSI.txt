KONTEKS SKRIPSI
===============
Judul kerja:
Pengembangan Sistem Presensi Madrasah Diniyah Berbasis Android dengan
Arsitektur Offline-First dan Notifikasi WhatsApp
(Studi Kasus Pondok Pesantren Qomaruddin)

Konsep aplikasi:
- Aplikasi Android Flutter.
- Backend Laravel REST API.
- Database PostgreSQL/Neon khusus skripsi.
- Database lokal Android menggunakan Room Database terenkripsi.
- Sinkronisasi offline-first dengan antrean/outbox lokal.
- WorkManager digunakan untuk mencoba sinkronisasi otomatis saat internet tersedia.
- Aktor utama: Admin dan Guru.
- Fokus sistem: presensi santri Madrasah Diniyah, bukan pembayaran atau fitur real lain.


FITUR YANG SUDAH DISESUAIKAN
============================
1. Login admin/guru.
2. Buku Induk / master data:
   - Guru
   - Kelas
   - Santri
   - Mata pelajaran
3. Presensi:
   - Pilih kelas
   - Pilih mata pelajaran
   - Pilih tanggal dan waktu
   - Status Hadir, Sakit, Izin, Alpa
   - Keterangan untuk Sakit/Izin/Alpa
4. Edit presensi.
5. Cancel/batalkan presensi.
6. Riwayat presensi.
7. Sinkronisasi offline-first:
   - pending
   - syncing
   - completed
   - failed
8. Notifikasi WhatsApp:
   - terkirim setelah presensi masuk server
   - memuat nama santri, NISN, tanggal, status, kelas, mata pelajaran
   - jika status Sakit/Izin/Alpa dan ada keterangan, keterangan ikut terkirim


WHATSAPP BOT
============
Bot WA Railway:
https://absensiandroid-production.up.railway.app

Backend Vercel:
https://absensi-android-skripsi.vercel.app/api

Environment penting:
- Railway bot punya `BOT_SECRET`.
- Vercel backend harus punya `WHATSAPP_BOT_SECRET` yang sama persis.
- Vercel backend harus punya:
  WHATSAPP_BOT_URL=https://absensiandroid-production.up.railway.app
  WHATSAPP_BOT_TIMEOUT=20

Status terakhir:
- Bot pernah berhasil mengirim notifikasi.
- Setelah redeploy Railway, bot bisa kembali `menunggu_qr`, jadi user perlu scan QR lagi.
- Jika notifikasi tidak masuk, cek dulu:
  1. Bot Railway `/status`
  2. Apakah status bot `aktif`
  3. Apakah secret Vercel sama dengan Railway
  4. Log bot `/log?n=10`

Template pesan WA terbaru:

[Madrasah Diniyah]
Yth. Wali dari Nama Santri (NISN)
Status kehadiran Ananda pada hari ini (Hari, Tanggal Bulan Tahun) adalah
Status Kehadiran

Kelas: Nama Kelas
Mata Pelajaran: Nama Mata Pelajaran

Terimakasih.

Jika ada keterangan:
Status Kehadiran
Keterangan: isi keterangan
