# PANDUAN BELAJAR FUNDAMENTAL KODING

Update: 26 April 2026
Project: Absensi Android + Laravel Backend

Dokumen ini dibuat khusus untuk belajar dasar-dasar koding yang dipakai dalam project ini. Isinya bukan sekadar teori umum, 
tetapi dikaitkan langsung dengan pola aplikasi Absensi Android: Flutter di frontend, Laravel di backend, PostgreSQL di database, 
REST API sebagai penghubung, dan sistem offline/cache di sisi Android.

## 1. Gambaran Besar Cara Kerja Aplikasi

Sebelum belajar kode satu per satu, pahami alur besarnya dulu.

```text
User membuka aplikasi Android
-> Flutter menampilkan UI
-> Flutter memanggil ApiService
-> ApiService mengirim HTTP request ke Laravel
-> Laravel route mengarah ke Controller
-> Controller memanggil Model/Service
-> Model membaca/menulis PostgreSQL
-> Laravel mengirim JSON response
-> Flutter membaca JSON
-> UI berubah sesuai data
```

Contoh sederhana:

```text
Admin buka menu Keuangan
-> Flutter request /api/payment-types
-> Laravel PaymentTypeController mengambil data payment_types
-> Backend kirim JSON daftar tipe pembayaran
-> Flutter tampilkan kartu pembayaran
```

Intinya:

- Flutter bertugas menampilkan dan mengirim input user.
- Laravel bertugas mengatur logic dan validasi.
- PostgreSQL menyimpan data utama.
- API JSON menjadi jembatan antara Flutter dan Laravel.

## 3. Fundamental Dart

Dart adalah bahasa yang dipakai Flutter.

Contoh variable:

```dart
final nama = 'Diki';
int umur = 20;
bool aktif = true;
double nilai = 88.5;
```

Penjelasan:

- `final` berarti nilai hanya diisi sekali.
- `String` untuk teks.
- `int` untuk angka bulat.
- `double` untuk angka desimal.
- `bool` untuk benar/salah.

Contoh list:

```dart
final siswa = ['Ahmad', 'Fatimah', 'Zainab'];
```

Contoh map:

```dart
final user = {
  'id': 1,
  'nama': 'Admin',
  'role': 'admin',
};
```

List dipakai untuk banyak data. Map dipakai untuk data yang punya key dan value.

## 4. Function

Function adalah blok kode yang bisa dipanggil ulang.

Contoh:

```dart
String formatNama(String nama) {
  return nama.trim();
}
```

Penjelasan:

- `String` pertama adalah tipe hasil.
- `formatNama` adalah nama function.
- `(String nama)` adalah parameter.
- `return` mengembalikan hasil.

Contoh function async:

```dart
Future<void> loadData() async {
  final data = await ApiService.getSiswa();
  print(data);
}
```

Penjelasan:

- `Future` berarti hasil datang nanti.
- `async` berarti function boleh menunggu proses.
- `await` menunggu request selesai.

Di project ini, function async banyak dipakai untuk:

- ambil data API;
- simpan cache;
- upload file;
- import/export;
- sync offline.

## 7. StatelessWidget dan StatefulWidget

`StatelessWidget` dipakai jika tampilan tidak berubah karena state internal.

```dart
class JudulPage extends StatelessWidget {
  const JudulPage({super.key});

  @override
  Widget build(BuildContext context) {
    return Text('Judul');
  }
}
```

`StatefulWidget` dipakai jika tampilan bisa berubah.

```dart
class CounterPage extends StatefulWidget {
  const CounterPage({super.key});

  @override
  State<CounterPage> createState() => _CounterPageState();
}

class _CounterPageState extends State<CounterPage> {
  int count = 0;

  @override
  Widget build(BuildContext context) {
    return ElevatedButton(
      onPressed: () {
        setState(() {
          count++;
        });
      },
      child: Text('$count'),
    );
  }
}
```

Penjelasan:

- `setState` memberi tahu Flutter bahwa tampilan perlu digambar ulang.
- Data seperti loading, list siswa, pilihan filter, dan form biasanya disimpan sebagai state.

## 8. State Loading, Success, Error

Saat aplikasi mengambil data, biasanya ada tiga kondisi:

```text
loading
success
error
```

Contoh:

```dart
bool isLoading = false;
String? errorMessage;
List<Map<String, dynamic>> data = [];
```

Pola umumnya:

```dart
Future<void> fetchData() async {
  setState(() {
    isLoading = true;
    errorMessage = null;
  });

  try {
    final result = await ApiService.getSiswa();
    setState(() {
      data = result;
    });
  } catch (e) {
    setState(() {
      errorMessage = e.toString();
    });
  } finally {
    setState(() {
      isLoading = false;
    });
  }
}
```

Penjelasan:

- `try` mencoba menjalankan kode.
- `catch` menangkap error.
- `finally` tetap jalan setelah selesai, baik sukses atau gagal.

## 9. API Service di Flutter

API Service adalah file yang menghubungkan Flutter ke Laravel.

Tugas API Service:

- membuat URL endpoint;
- mengirim request;
- membawa token/session jika diperlukan;
- membaca JSON response;
- melempar error jika gagal.

Contoh konsep:

```dart
final response = await http.get(Uri.parse('$baseUrl/api/siswa'));
```

Jika backend mengirim JSON:

```json
{
  "success": true,
  "data": [
    { "id": 1, "nama": "Ahmad" }
  ]
}
```

Flutter membaca:

```dart
final body = jsonDecode(response.body);
final data = body['data'];
```

Aturan:

- jangan menaruh logic bisnis terlalu banyak di UI;
- request API sebaiknya lewat service;
- response harus dicek status code-nya;
- error harus ditampilkan dengan pesan yang jelas.

## 13. Laravel Controller

Contoh konsep:

```php
class SiswaController extends Controller

```

Tugas controller:

## 17. Foreign Key

Foreign key adalah pengaman relasi.

Contoh:

```text
siswa.class_id -> classes.id
```

Artinya:

- siswa menyimpan ID kelas;
- ID kelas harus ada di tabel classes;
- tidak boleh asal mengetik nama kelas sebagai relasi.

Manfaat:

- data lebih aman;
- typo berkurang;
- relasi mudah dilacak;
- laporan lebih konsisten.

## 18. ID vs Text

Ini bagian penting dalam project.

Text untuk tampilan:

```text
Nama siswa: Ahmad
Nama kelas: Sifir Awal A
Nama kota: Gresik
```

ID untuk relasi:

```text
student_id = 5
class_id = 2
city_id = 120
```

Jangan memakai:

```sql
where nama_guru = 'Diki'
```

Gunakan:

```sql
where teacher_id = 2
```

Kenapa?

- nama bisa typo;
- nama bisa sama;
- huruf besar/kecil bisa beda;
- ID lebih pasti.

## 25. Error Handling

Error handling adalah cara menangani masalah tanpa membuat aplikasi crash.

Di Flutter:

```dart
try {
  await saveData();
} catch (e) {
  showMessage('Gagal menyimpan data');
}
```

Di Laravel:

```php
try {
    // logic simpan
} catch (\Throwable $e) {
    return response()->json([
        'success' => false,
        'message' => 'Gagal menyimpan data',
    ], 500);
}
```

Aturan:

- jangan menampilkan error teknis mentah ke user;
- log error teknis untuk developer;
- user cukup diberi pesan yang bisa dipahami;
- validasi input sebelum simpan ke database.

## 26. Validasi

Validasi memastikan input benar.

Contoh Laravel:

```php
$validated = $request->validate([
    'nama' => ['required', 'string', 'max:255'],
    'class_id' => ['nullable', 'integer', 'exists:classes,id'],
]);
```

Penjelasan:

- `required` wajib diisi;
- `string` harus teks;
- `max:255` panjang maksimal;
- `integer` harus angka;
- `exists:classes,id` ID harus ada di tabel classes.

Validasi adalah pagar supaya database tidak rusak.

## 27. Role Access

Contoh benar:

## 39. Contoh Belajar Entry Point Flutter

File:

```text
lib/main.dart
```

Yang dipelajari:

- aplikasi mulai dari `main()`;
- Flutter perlu `WidgetsFlutterBinding.ensureInitialized()`;
- `SyncService.init()` dipanggil sebelum aplikasi jalan;
- session dicek lewat `SessionService.isLoggedIn()`;
- route awal ditentukan dari status login;
- theme global memakai warna dan font utama.

Bagian penting:

```dart
void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await SyncService.init();
  final isLoggedIn = await SessionService.isLoggedIn();
  runApp(MyApp(isLoggedIn: isLoggedIn));
}
```

```sql
select s.id, s.nama, s.class_id, c.name as nama_kelas
from siswa s
left join classes c on c.id = s.class_id
order by s.id desc
limit 20;
```

Yang dipahami:

```text
siswa menyimpan class_id.
Nama kelas tampil dari tabel classes.
Kalau nama kelas typo di UI, relasi tetap aman selama class_id benar.
```

## 65. Contoh Latihan Membaca Pembayaran

Misal ingin tahu transaksi pembayaran memakai metode apa.

File yang dicek:

```text
absensi_backend/app/Models/PaymentTransaction.php
absensi_backend/app/Models/PaymentMethod.php
absensi_backend/app/Models/PaymentStatus.php
absensi_backend/app/Models/PaymentType.php
```

SQL latihan:

```sql
select
  pt.id,
  pt.siswa_id,
  pt.payment_type_id,
  pt.payment_method_id,
  pm.name as metode,
  pt.payment_status_id,
  ps.name as status
from payment_transactions pt
left join payment_methods pm on pm.id = pt.payment_method_id
left join payment_statuses ps on ps.id = pt.payment_status_id
order by pt.id desc
limit 20;
```

Yang dipahami:

```text
Metode pembayaran tidak bergantung pada text bebas.
Metode tampil dari payment_methods.
Status tampil dari payment_statuses.
```

## 66. Cara Praktek Aman Tanpa Merusak Project

Untuk belajar, lakukan ini:

```text
1. Baca file.
2. Catat alur.
3. Jalankan command pengecekan.
4. Jangan edit UI dulu.
5. Kalau ingin coba edit, ubah komentar atau log kecil saja.
6. Setelah itu pakai git diff untuk melihat perubahan.
7. Kembalikan jika tidak diperlukan.
```

Command aman:

```bash
flutter analyze --no-pub
php artisan route:list --path=api
git status
git diff
```

Jangan lakukan saat data sungguhan:

```bash
php artisan migrate:fresh --seed
```

Kecuali memang database masih dummy dan siap dihapus.
